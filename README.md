# Crop Image - Online for Free, Instantly, No Watermarks

## Introduction

Crop Image is an online image cropping and conversion tool that supports multiple image formats.

It offers free, instant, and no watermark - free services.

Users can easily upload images for single or batch cropping or format conversion with simple and convenient operations.

## Features

- Image Cropping: Supports single and batch image cropping to meet various needs.
- Format Conversion: Converts images in formats like JPG to WEBP while maintaining high quality.
- Multi - language Support: Achieves multi language support through next-intl, facilitating global users.
- Responsive Design: User friendly interface adaptable to different device screen sizes.

## Running locally

- run `npm i` to install the dependencies.

- Then, run `npm run dev` to start the development server and visit [http://localhost:3000](http://localhost:3000) to see the website running.
